# 第三方许可补充

部分锁定依赖的 crates.io 发布包没有附带许可全文。`manifest.json` 按包名、版本和原始许可表达式记录受控的补充文件、来源 URL 及 SHA-256；打包脚本不联网获取这些补充文件，哈希不符或新依赖缺少许可时直接失败。

大部分文件来自该发布包 `.cargo_vcs_info.json` 指向的同一上游源码提交。`convert_case 0.4.0` 和 `simd_helpers 0.1.0` 使用紧随原发布提交的上游许可补充提交，具体来源在清单中。它们不是原 crates.io 包自带的文件。

`mac 0.1.1` 的原发布包与固定发布标签只声明 MIT / Apache-2.0，并保留作者信息；发行包选用 Apache-2.0 的标准条款。`seahash 4.1.0` 的原发布包只声明 MIT 并列出作者，没有附带许可全文；发行包附 SPDX 的标准 MIT 条款模板及原包声明。模板占位符不是上游版权声明，不据此编造版权年份。若附有早期项目版权文件，其历史来源与当前包原始声明分别保留。

收集器同时保留这些包的原 `Cargo.toml` / `Cargo.toml.orig` 和 README，补充文件不修改或代替原包的授权声明。第三方文件保持各自许可；本项目的 MIT 不将这些文件重新许可为本项目资源。变更依赖时必须重新审核。
