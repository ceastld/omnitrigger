# 插件动作、程序与简单脚本

OmniTrigger 可以在键盘或鼠标组合命中后执行插件动作、外部程序或脚本。命令在应用层执行，不进入输入 Hook 的同步匹配路径。无参数截图可直接使用动作库；高级调用仍可填写程序，或显式指定 PowerShell、Node.js 等解释器。

## 从动作库配置 RaiShot

打开“动作库”并点击“安装 RaiShot 插件”，下载并校验固定版本的截图程序、随包 DLL 和许可文件。完成后，截图动作的所有绑定共享同一路径。已安装 RaiShot 时，也可填写本机 `raishot-cli.exe` 的完整路径并点击“保存并启用”。下载访问要求和安装目录见 [快速开始的截图插件说明](GETTING_STARTED.md#安装截图插件)。

点击截图卡片的“设置触发”，默认组合 `左 Ctrl + 左 Alt + A` 会进入草稿。可以保留默认，点击“重新录制”录制自己的组合，或“选择预设”更换触发方式。动作与触发草稿相互独立，更换触发方式不会将截图改为打开面板。“恢复默认”同样只修改草稿，点击“添加触发器”或“保存动作”且通过冲突检查后才生效。

“测试动作”真实运行当前草稿，不保存配置、不增加组合命中次数。组合、浮动面板和测试共用截图组的单并发限制；一个截图命令尚未结束或结果尚未处理时，其他截图绑定也拒绝启动，不排队补跑。停用插件或程序缺失时保留绑定，移出实际监听注册集，不退化成仅提示。

## 在界面中配置

录制组合后，或打开已有触发器的详情，选择“运行程序”，填写：

| 字段 | 填写方式 |
| --- | --- |
| 程序 | 可执行文件路径，不加外层引号；推荐完整路径。脚本填写其解释器程序。 |
| 参数 | JSON 字符串数组，每个参数独立填写；没有参数时填 `[]`。 |
| 工作目录（可选） | 程序运行时的当前目录；留空时继承 OmniTrigger 的工作目录。它不负责寻找或安装程序。 |

路径中的空格或中文不需要拆分。例如参数 `"C:\\Scripts\\我的截图.ps1"` 是一个完整字符串。

新触发器填写后点击“添加触发器”；修改已有触发器后点击“保存动作”，以后实际按键触发使用保存的动作。保存配置本身不会执行命令。“测试动作”会立即执行当前表单中的草稿，即使尚未保存，也会真实启动程序；测试前先核对程序和参数。测试不会计入真实输入的命中次数。

需要隔离试用时，可用 `omnitrigger.exe --config "C:\Tests\bindings.json"` 指定另一份配置；文件不存在时加载示例，保存后写入该路径。

## 直接调用 RaiShot

最简单的配置：

| 字段 | 值 |
| --- | --- |
| 程序 | `C:\Apps\RaiShot\raishot-cli.exe` |
| 参数 | `["--capture"]` |
| 工作目录 | 留空，或 `C:\Apps\RaiShot` |

上表是“运行程序”的手动配置方式；动作库的 RaiShot 适配会生成同样的 `--capture` 调用，并使用程序所在目录作为工作目录。原始程序动作不根据路径自动转换为插件，也不自动参加插件截图组的互斥。

请将 `raishot.exe`、`raishot-cli.exe`、`raishot-gpui.exe` 保持在同一目录。`raishot-cli.exe --capture` 启动一次独立截图会话，并等待截图工作进程退出；它不经过托盘的预备进程。正常退出只代表进程返回成功退出码，取消截图也可能正常退出，不能据此认定已经生成图片。

RaiShot 托盘另有 `raishot.exe --region` 入口：已有托盘时交接截图请求后退出，首次启动则成为常驻进程。OmniTrigger 当前会跟踪该进程至退出，首次常驻会让同一绑定持续显示执行中并拒绝重复执行，因此本轮建议使用上面的 CLI 配置。

## Node.js 脚本

[raishot-capture.mjs](../examples/raishot-capture.mjs) 使用 Node.js 的 `execFile` 和顶层 `await`，等待 RaiShot CLI 结束；启动失败或非零退出会抛出错误。脚本不自动重试。

先安装 Node.js，再在 PowerShell 中设置实际程序路径并运行：

```powershell
$env:RAISHOT_CLI = 'C:\Apps\RaiShot\raishot-cli.exe'
node 'C:\Apps\OmniTrigger\examples\raishot-capture.mjs'
```

未设置 `RAISHOT_CLI` 时，脚本从 `PATH` 查找 `raishot-cli.exe`。在 OmniTrigger 中运行脚本时，需要让启动 OmniTrigger 的环境包含这个变量；也可以自行将脚本中的默认值改为实际完整路径。

对应的触发器配置：

| 字段 | 值 |
| --- | --- |
| 程序 | `C:\Program Files\nodejs\node.exe`（以实际安装路径为准） |
| 参数 | `["C:\\Apps\\OmniTrigger\\examples\\raishot-capture.mjs"]` |
| 工作目录 | 留空 |

只检查示例语法、避免启动截图时可用：

```powershell
node --check .\examples\raishot-capture.mjs
```

## PowerShell 脚本

将脚本保存为本机文件，例如 `C:\Scripts\capture.ps1`，再配置解释器：

| 字段 | 值 |
| --- | --- |
| 程序 | `pwsh.exe`（需已安装且在 `PATH` 中，或填写完整路径） |
| 参数 | `["-NoProfile", "-File", "C:\\Scripts\\capture.ps1"]` |
| 工作目录 | 按脚本需要填写，或留空 |

OmniTrigger 不隐式调用 Shell，不拼接命令行，不解释管道、重定向或环境变量表达式。需要这些功能时，由显式选择的解释器和脚本处理。PowerShell 的退出码由脚本负责传递；脚本调用外部程序后如需报告失败，应检查 `$LASTEXITCODE` 并返回非零退出码。

## 执行状态与边界

- 最多同时处理 4 项命令，包括待启动、运行中和尚未读取的结束结果；同一触发器上一次命令尚未结束或结果尚未处理时，拒绝重复执行，不排队补跑。插件动作还按共享组接纳，RaiShot 截图组同时最多 1 项。
- 启动失败和进程退出状态显示在界面及触发记录中。进程正常退出不等于插件业务成功；当前没有图片路径、工作流结果或插件完成回执。
- 读取进程状态失败时显示未知并继续观察，保留执行占用；无法确认退出时不放行同组的新调用。执行线程或事件通道断开后不再接纳新命令。
- OmniTrigger 不捕获或显示外部程序的标准输出和标准错误，也不提供交互式终端；脚本需要的详细日志应自行写入文件。控制台窗口隐藏，外部程序自己的界面仍可正常显示。
- 不自动重试，不设置自动超时，也不提供终止外部进程的按钮。退出 OmniTrigger 不会终止已启动的外部程序；尚未启动的请求不再执行。
- 程序、参数和可选工作目录随绑定保存在本机配置中。命令参数最多 128 项，整个命令配置最多 64 KiB；输入错误会明确拒绝。

内置动作清单、默认快捷键和配置迁移见 [插件动作与快速绑定设计](PLUGIN_SYSTEM.md)。
