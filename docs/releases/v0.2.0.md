# OmniTrigger v0.2.0 · Windows 预览版

## 安装与配置

下载 `OmniTrigger-0.2.0-windows-x86_64-setup.exe`，按向导安装到当前 Windows 用户。开始菜单的 **OmniTrigger** 打开日常配置。原有绑定、动作目录、轮盘和外观仍从 `%LOCALAPPDATA%\OmniTrigger` 读取，卸载和重装均保留。

**OmniTrigger 测试** 打开独立的本机测试配置档。首次使用加载示例，之后保留上次编辑的内容，窗口标题显示测试标识。测试实例默认关闭键鼠监听，可以和日常实例并用。配置按本机 Windows 用户保存。

便携版使用 `OmniTrigger-0.2.0-windows-x86_64.zip`。两种下载的摘要均见 `SHA256SUMS.txt`。建议使用 Windows 11 x64，需要 Microsoft Visual C++ v14 x64 运行库。安装程序和应用均未签名。

## 相比首个预览版

- 日常主窗口关闭后收至托盘，键鼠监听继续工作。单击图标恢复窗口，右键菜单可退出。测试窗口关闭即退出。
- 设置页可检查更新、校验下载并重启到新版。
- 鼠标手势支持显示轨迹和形状匹配，动作轮盘可以按应用配置。
- 动作包支持 JavaScript 入口。浏览器连接器、轻量脚本宿主等依赖沿用各自的安装方式。

## 验证范围

发行 CI 验证工作区、示例配置、依赖许可、安装与重装、开始菜单入口以及安装器和便携 ZIP 的 SHA-256。系统保留组合、权限较高的窗口、第三方 Hook 和显示器驱动仍会影响实际行为。Windows 10 和不同硬件组合的完整兼容性尚待验证。
