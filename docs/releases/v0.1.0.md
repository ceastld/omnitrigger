# OmniTrigger v0.1.0 · Windows 预览版

首个 Windows x64 开发预览版，API 和配置格式仍可能调整。

## 下载与运行

下载 `OmniTrigger-0.1.0-windows-x86_64.zip`，完整解压后运行 `omnitrigger.exe`。使用 `SHA256SUMS.txt` 中的 SHA-256 核对 ZIP；包内包含项目许可证、依赖许可及第三方通知。

建议使用 Windows 11 x64；Windows 10 尚未完成全面兼容验证。本版本需要 [Microsoft Visual C++ v14 Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)，无需 Rust 或开发工具。程序未经代码签名，未提供安装器或自动更新。

首次启动加载示例，配置保存在 `%LOCALAPPDATA%\OmniTrigger`。需要隔离试用时，可使用 `omnitrigger.exe --config <独立目录>\bindings.json`。

## 主要功能

- 键盘与鼠标组合录制、注册、冲突检查，以及长按、快速拖拽和鼠标区域条件。
- 触发器管理、23 个可编辑预设、浮动触发面板，以及支持多圈布局与按应用切换的动作轮盘。
- 本地提示、快捷键、本地步骤、窗口操作、系统音量和硬件亮度调节、外部程序及脚本。
- 本地配置保存与旧版迁移备份、输入诊断、暂停 / 恢复与监听重建。
- 可选截图插件适配。截图程序按用户操作另行下载，未合并进本发行包；下载源可能需要相应仓库访问权限。

## 已知限制与验证范围

输入补发会改变时序，不能保证无损恢复；系统保留组合、安全桌面、其他软件的输入拦截及不同权限窗口仍受 Windows 限制。亮度调节依赖硬件和驱动支持。外部程序退出不代表其业务操作已完成，暂停或退出也不会终止已经启动的外部程序。

当前没有双击 / 连击、按设备区分、系统托盘、插件市场或自动更新。测试动作会真实发送输入、修改剪贴板、改变设备设置或启动程序；配置保存本身不执行动作。

本地在 Windows 11（系统内部版本 26200）完成工作区测试、格式检查、Clippy、应用构建、示例配置和真实 Hook 安装 / 卸载检查。发布流程还会在 Windows runner 执行自动检查后才公开资产。自动化检查不覆盖全部图形交互、显示器、驱动和权限组合，也不等于完成干净终端用户环境的全面验证。
