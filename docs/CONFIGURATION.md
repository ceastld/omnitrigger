# 配置文件与隐私

OmniTrigger 的绑定、插件与轮盘配置都保存在本机 JSON 文件中。本页说明文件位置、版本迁移、外部程序的运行方式及隐私边界；各动作的字段见对应专题文档。

## 配置文件位置

绑定、提示文字、位置条件与动作参数保存在 `%LOCALAPPDATA%\OmniTrigger\bindings.json`；没有 `LOCALAPPDATA` 时使用系统临时目录下的 `OmniTrigger\bindings.json`。初次运行加载示例，之后保留用户配置，编辑后自动保存。

启动时加 `--config <文件路径>` 可以使用独立配置，后续编辑保存到该文件；`--check-config` 只读检查所选配置，不安装 Hook 或执行动作。完整参数见[快速开始](GETTING_STARTED.md#命令行参数)。

| 文件 | 位置 | 内容 |
| --- | --- | --- |
| `bindings.json` | 默认目录或 `--config` 指定 | 绑定、触发描述、位置条件、提示与动作参数 |
| `plugins.json` | 与绑定文件同级 | 插件启停和共享程序路径 |
| `plugins\raishot\manifest.json` | 与绑定文件同级 | 可选的开发者 RaiShot 动作清单；缺失时使用内置清单 |
| `wheels.json` | 与绑定文件同级 | 轮盘名称、配色、槽位与应用覆盖 |
| `plugins\raishot\runtime\0.4.15` | 与绑定文件同级 | 早期版本下载的截图插件运行文件，仍可被复用；新下载位于 `%LOCALAPPDATA%\Programs\RaiShot` |
| `actions\<包目录>\action.json` | 与绑定文件同级的 `actions` | 本地动作包清单及其引用的 JS 入口；启动时加载 |

## 版本与备份

浏览器连接器的本机状态独立保存在配置同级 `browser-connector.json`，版本程序位于 `plugins/browser-connector/runtime/0.1.0`。用户点击安装后，本机注册与启动自动完成，这些内部文件无需手工编辑。实现细节见[浏览器连接器](BROWSER_EXTENSION.md)。

`bindings.json` 读取兼容版本 1–9，保存使用版本 9；首次保存旧配置前创建 `bindings.json.v<旧版本>.bak` 备份，备份失败不会覆盖原配置。版本 8 增加 `invoke` 动作引用，版本 9 增加 `browser` 浏览器动作，既有动作形态保持兼容。回退旧程序时需恢复对应备份。

插件启停和共享程序路径保存在绑定文件同级的 `plugins.json`，通过“启用 RaiShot”自动识别或下载安装后保存。使用 `--config` 时，插件设置、可选动作清单和下载目录也位于所选配置文件的目录，便于隔离试用；复用的已有安装仍保留在原位置。`plugins\raishot\manifest.json` 在启动或刷新时读取，清单损坏或版本不兼容会明确报错并保留原绑定，不回退到内置动作掩盖错误。清单格式与手动路径排障见[插件说明](PLUGIN_SYSTEM.md#开发排障入口)。旧程序动作保持原始参数，不自动转换成插件引用。

轮盘内容保存在绑定文件同级的 `wheels.json`，读取版本 1–4，保存版本 4，版本 3 支持 `invoke` 动作、版本 4 支持 `browser` 动作；可选的 `position` 保存圈号、分区和半分区偏移，`app_overrides` 保存按进程文件名匹配的完整槽位替换。呼出组合在绑定文件中保存 `show_wheel` 动作与轮盘标识。每个槽位独立保存动作参数，不随复制来源的绑定更改。轮盘引用缺失时保留绑定并标记不可用；损坏或不支持的轮盘配置不会被保存操作覆盖，保存失败时保留原文件。配置形态见[自定义轮盘](RADIAL_WHEELS.md)。

动作包引用保存 `package_id`、`action_id`、`action_version` 与 JSON 对象 `input`。保存配置只验证调用结构；运行时解析包与动作版本。包缺失或不兼容时保留原引用及参数，将对应绑定标记不可用，不静默改为其他动作。包清单的 `schema_version`、包发布 `version`、动作契约 `version` 与绑定文件版本独立，详见[动作包说明](ACTION_PACKAGES.md)。

## 外部程序与脚本

普通“运行程序”的程序与参数逐项传递，不默认经过 Shell，不展开环境变量或引号，也不自动重试。外部程序按当前用户权限运行；仅启动自己信任的程序和脚本。进程正常退出不代表插件业务已完成，这条执行路径不采集标准输出与错误输出。暂停监听只阻止新触发，退出 OmniTrigger 不会终止普通命令已启动的外部程序。见[程序与脚本](COMMAND_ACTIONS.md)。

JS 动作包使用独立 Node 宿主和结构化结果协议，`ctx.process.run` 有界采集进程输出。脚本按当前用户权限执行，独立宿主不是安全沙盒；脚本及其启动的程序可能访问文件或网络。取消不回滚副作用，具体收尾边界见[动作包说明](ACTION_PACKAGES.md#执行与权限边界)。

## 隐私

当前应用不提供遥测、云同步或输入上传。插件安装会访问 GitHub 下载程序及运行依赖，不上传输入事件或截图；全局监听用于本机匹配与录制，触发记录和输入诊断仅保留在进程内。配置中的提示文字、诊断截图可能包含个人内容，报告问题前请自行脱敏。

可试用的配置示例位于仓库的 [`examples/`](../examples/)，均可通过 `--check-config` 验证。
