# 配置文件与隐私

OmniTrigger 的绑定、插件与轮盘配置都保存在本机 JSON 文件中。本页说明文件位置、版本迁移、外部程序的运行方式及隐私边界；各动作的字段见对应专题文档。

## 配置文件位置

绑定、提示文字、位置条件与动作参数保存在 `%LOCALAPPDATA%\OmniTrigger\bindings.json`；没有 `LOCALAPPDATA` 时使用系统临时目录下的 `OmniTrigger\bindings.json`。初次运行加载示例，之后保留用户配置，编辑后自动保存。

启动时加 `--config <文件路径>` 可以使用独立配置，后续编辑保存到该文件；`--check-config` 只读检查所选配置，不安装 Hook 或执行动作。完整参数见[快速开始](GETTING_STARTED.md#命令行参数)。

| 文件 | 位置 | 内容 |
| --- | --- | --- |
| `bindings.json` | 默认目录或 `--config` 指定 | 绑定、触发描述、位置条件、提示与动作参数 |
| `plugins.json` | 与绑定文件同级 | 插件启停和共享程序路径 |
| `wheels.json` | 与绑定文件同级 | 轮盘名称、配色、槽位与应用覆盖 |
| `plugins\raishot\runtime\0.4.15` | 与绑定文件同级 | 按用户操作下载的截图插件运行文件 |

## 版本与备份

`bindings.json` 读取兼容版本 1–7，保存使用版本 7；首次保存旧配置前创建 `bindings.json.v<旧版本>.bak` 备份，备份失败不会覆盖原配置。回退旧程序时需恢复对应备份。

插件启停和共享程序路径保存在绑定文件同级的 `plugins.json`。使用 `--config` 时，插件设置和下载目录也位于所选配置文件的目录，便于隔离试用。旧程序动作保持原始参数，不自动转换成插件引用。

轮盘内容保存在绑定文件同级的 `wheels.json`，读取版本 1–2，保存版本 2；可选的 `position` 保存圈号、分区和半分区偏移，`app_overrides` 保存按进程文件名匹配的完整槽位替换。呼出组合在绑定文件中保存 `show_wheel` 动作与轮盘标识。每个槽位独立保存动作参数，不随复制来源的绑定更改。轮盘引用缺失时保留绑定并标记不可用；损坏或不支持的轮盘配置不会被保存操作覆盖，保存失败时保留原文件。配置形态见[自定义轮盘](RADIAL_WHEELS.md)。

## 外部程序与脚本

程序与参数逐项传递，不默认经过 Shell，不展开环境变量或引号，也不自动重试。外部程序按当前用户权限运行；仅启动自己信任的程序和脚本。进程正常退出不代表插件业务已完成，标准输出与错误输出当前不采集。暂停监听只阻止新触发，退出 OmniTrigger 不会终止已启动的外部程序。见[程序与脚本](COMMAND_ACTIONS.md)。

## 隐私

当前应用不提供遥测、云同步或输入上传。插件安装会访问 GitHub 下载程序及运行依赖，不上传输入事件或截图；全局监听用于本机匹配与录制，触发记录和输入诊断仅保留在进程内。配置中的提示文字、诊断截图可能包含个人内容，报告问题前请自行脱敏。

可试用的配置示例位于仓库的 [`examples/`](../examples/)，均可通过 `--check-config` 验证。
