# 发送按键与快捷键

在触发器详情中选择“发送快捷键”，填写单个按键或修饰键组合，保存后切换到目标窗口测试。

| 输入示例 | 发送内容 |
|---|---|
| `Backspace` | 退格 |
| `Left` / `Up` / `Right` / `Down` | 方向键 |
| `Ctrl+C` | 复制快捷键 |
| `Ctrl+Shift+Left` | 按词向左选择 |
| `RightCtrl+Home` | 右 Ctrl 与 Home |

支持字母、数字、F1–F24、导航键、常用编辑键及小键盘。`Ctrl`、`Shift`、`Alt`、`Win` 默认表示左侧，可明确填写 `RightCtrl` 等右侧名称。最多四种修饰键加一个普通键；重复修饰键、纯修饰键或多个普通键会报错，不自动改写。

每次组合触发发送一次完整按下与释放，长按动作键不会连续发送。按键动作有独立后台队列，最多四个待处理或未读结果，与外部程序执行分开。队列满、权限隔离或输入失败会在动作状态中报错，不自动重试。

提交时记录前台窗口，执行前窗口已切换则取消，不主动切换焦点。已按住且属于目标快捷键的修饰键只借用，不补发释放；存在其他已按住的修饰键或目标键时取消。自身注入带专用标记，不再次触发组合或进入录制。其他程序的 Hook 仍可能拦截输入，部分成功后的释放收尾也不能保证无损恢复。

配置使用版本 5 的动作字段，例如：

```json
"action": { "kind": "send_shortcut", "keys": [162, 67] }
```

`keys` 依次为 Windows 左右明确的虚拟键码，最后一个是目标键；上例为左 Ctrl（162）与 C（67）。旧程序不认识该动作会明确拒绝读取，回退前请恢复配置备份。

[CapsLock 导航示例](../examples/capslock-navigation.json) 配置了 `CapsLock+O → Backspace`，`I/J/K/L → ↑/←/↓/→`。可独立试用：

```powershell
.\target\debug\omnitrigger.exe --config .\examples\capslock-navigation.json
```

程序编辑会保存到指定文件；需保留原示例时，先复制到 `.local`。单独按下 CapsLock 仍遵循前缀回放规则，释放时保留系统原有功能。应用黑名单、按住方向键连续移动和单按 CapsLock 禁用尚未提供。
