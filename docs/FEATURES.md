# 当前功能与交互说明

本页描述当前 Windows 测试程序已实现的功能。安装和运行命令见 [README](../README.md)，专题说明见[文档目录](README.md)。

首版 Windows 测试程序使用 Rust + GPUI，提供全局键盘/鼠标组合、长按与快速拖拽监听、预设、录制、注册、浮动面板和自定义轮盘。浮动轮盘以圆形深色底盘承载环形动作扇区，底盘以外透明，不显示系统矩形边框；选中时扇区、外圈刻度和中心指针以轮盘配色点亮，顶部停靠独立的设置和关闭控件。核心与界面独立，不依赖其他产品代码。

界面为深色霓虹风格：薄荷到天青的渐变强调色、带光晕的立体键帽，并按动作类型着色区分。左侧栏包含监听状态卡、浮动触发面板入口（显示当前呼出组合）、呼出组合录制和“动作库 / 轨道轮盘 / 触发预设 / 触发器 / 触发记录 / 输入诊断”页面切换。触发器页上方为统计胶囊，中间为触发器列表，每行带动作类型图标、组合键帽与命中次数；右侧为悬浮详情卡，包含组合展示区、“按下即触发 / 长按触发 / 快速拖拽”三种触发方式、动作类型选择格，底部固定保存、测试与删除按钮。底部状态栏显示监听状态与输入计数。

界面延伸到标题栏：侧栏与各页面底色直达窗口顶部，应用名所在行和页面顶部空白处可拖动窗口；右上角保留系统原生的最小化、最大化、关闭按钮（含悬停效果与 Windows 11 贴靠布局）。程序图标为键帽加闪电，已嵌入 `omnitrigger.exe`，用于窗口、任务栏与资源管理器。若标题栏接管失败，界面提示错误并改用系统标题栏。

当前可测试：

- 预置 `CapsLock + W`、`鼠标侧键 1 + 滚轮上滚/下滚`，组合以键帽形式显示，鼠标按键带图标、滚轮带方向箭头。
- 新配置预置 `CapsLock + Space` 切换浮动触发面板的显示状态，右键长按 `300ms` 每次在当前鼠标位置显示面板，已打开时重新定位。面板以鼠标位置为中心显示三列动作卡片，高度随行数变化，不移动鼠标，靠近屏幕边缘时调整位置以保留在工作区内。面板是无焦点浮窗，不抢占前台，原窗口保持输入焦点；面板可见时，输入采集只接管单独按下的方向键、`1`–`9`、`Esc`，以及方向键选择后的 `Enter`。点击筛选框后面板才取得前台并接收文字筛选，收起时交还前台。底部说明栏显示悬停或选中动作的组合与状态。点击或按键运行后先收起再执行。`Esc`、点击面板以外的位置或关闭按钮均可收起。停用、执行中或未就绪的动作不可运行，打开面板的绑定不作为卡片显示。
- 面板启动时预创建并保持隐藏，之后复用同一窗口及图形资源；触发通知直接唤醒界面，不等待维护轮询。长按阈值保持用户配置的数值，显示仍受系统调度与屏幕刷新影响。
- 面板以不激活方式显示，不模拟 Alt 等按键；靠物理外部点击与 `Esc` 收起。点击筛选框时才使用原生前台请求，系统未授予焦点时仍可点击动作。“输入诊断”还提供 Hook 本体、下游 Hook 链和补发的最大墙钟耗时及慢调用次数。
- 输入补发由独立线程执行，Hook 回调只做有界匹配与排队；等待补发时按顺序交付后续离散输入，鼠标移动继续透传，不重放位移。交付失败或队列满时暂停监听并尽力完成必要的释放；这仍不能保证无损恢复。
- Windows 长按优先使用一次性高精度等待计时器，消息持续到来时也检查到期时间；系统不支持时依次回退普通等待计时器、`SetTimer`。“输入诊断”显示实际计时方式、长按判定和面板提交耗时，以及移动、切窗和其他取消次数。
- “触发预设”提供 23 个可编辑模板，按五组展示，包括八种屏幕边角、右键快速拖拽、右键 / 中键 / 侧键长按、键盘长按和常用键鼠组合。选择预设会保留当前动作，确认参数并保存才会生效。普通按下、长按、快速拖拽是触发方式，鼠标位置是条件，提示、发送快捷键、系统调节、程序或轮盘是动作，三者分别配置。右键快拖默认在 `180ms` 之前移动至少 `18px`，可与同组合的静止长按 `300ms` 共存，两者在同次按压中互斥。详见[触发预设](TRIGGER_PRESETS.md)。
- “鼠标位置条件”可选四个角落、四条边及自定义物理矩形，并与滚轮、按键、长按或快拖组合。屏幕边角使用完整显示器范围，排除多屏共享边段及连接角；部分连接的边只排除相接部分。重新录制时保留已选条件，冲突由同一 `TriggerSpec` 检查。详见[鼠标区域条件](POINTER_REGIONS.md)。
- “系统调节”动作原生提供音量和硬件屏幕亮度的增减，步长为 1–100 个百分点。音量控制默认多媒体输出；亮度使用触发时鼠标所在屏幕的 DDC/CI 或精确匹配的内屏 WMI 接口，不支持时明确报错。调节在专用工作线程执行，同向快速滚动可合并，反馈使用设备读回值。四条边缘滚轮示例见 [screen-edge-adjustments.json](../examples/screen-edge-adjustments.json)，不会自动写入已有配置。
- 左侧“打开触发面板”可直接试用；“录制面板呼出组合”可录制键盘或鼠标组合，保存后生效。旧配置保持原有绑定，不自动添加组合，使用侧栏入口录制即可。详见[浮动面板说明](TRIGGER_PANEL.md)。
- “轨道轮盘”页可创建多个命名轮盘，选择三种配色并编辑独立动作。原有 1–8 槽均分布局保持兼容；显式 `position` 支持三圈稀疏方位、每圈最多 16 个分区及半分区偏移，每组最多 48 槽，空方位不会压缩。默认“编辑轨道”包含复制、粘贴、全选和撤销。“设置呼出组合”从右键快速拖拽预设生成草稿，保存且通过冲突检查后才注册；已有同轮盘的快拖绑定时直接进入编辑。
- 轮盘可用 `app_overrides` 按前台进程文件名选择整组槽位，匹配不区分大小写；进程名无法读取或没有匹配项时使用全局槽位。打开时冻结选中的定义，显示与执行使用同一快照。普通呼出时，数字键覆盖前八项，方向键可以遍历全部可用动作。
- 快速拖拽打开轮盘后，按固定物理起点计算方向，显式多圈布局将位移除以冻结的显示缩放后按半径选圈，松开原鼠标键执行。默认回到起点 `9px` 内取消，最外圈向外延伸；屏幕边缘的布局调整不改变选槽起点。首帧显示前已松开时，也按最终向量决定执行或取消。旧的 `CapsLock + Tab` 等按下呼出绑定保留点击、数字键和方向键选择方式。轮盘不抢焦点、不移动鼠标，切窗、暂停或录制会取消。详见[自定义轮盘](RADIAL_WHEELS.md)。
- 点击“录制组合”，按住前缀，再按目标键或滚动滚轮，全部松开后完成录制；录制期间实时显示已按住的键，`Esc` 取消。录制会拦截全部输入，鼠标点击也会被录下。
- 录完立即按注册规则检查：与已有组合重复、目标键与其他组合的前缀冲突、单独左/右键按下等情况会指出冲突的触发器，可查看或重新录制，不覆盖原有绑定。单独左/右键可以选择长按或快速拖拽方式后再注册。
- 填写提示消息后点击“添加触发器”；同一份触发器描述用于录制结果、注册验证和运行时匹配。
- “仅提示”动作在屏幕右下角显示 4 秒提示，带组合键帽和倒计时条；提示浮层不激活窗口。程序动作直接执行，避免截图时将提示浮层拍入。
- 列表显示每条触发器本次运行的命中次数与最近时间（有命中时显示）；开关可启用/停用，详情卡中编辑消息与动作、测试提示，删除需再次点击确认。
- “动作库”内置 RaiShot 截图动作及默认快捷键 `左 Ctrl + 左 Alt + A`。安装插件会下载截图程序及随包运行库，配置由多个绑定共享；选择“设置触发”只填入草稿，可以自定义组合、选择触发预设或恢复默认，保存前检查冲突。
- 动作可选择“发送快捷键”，支持 `Backspace`、方向键、`Ctrl+C`、`Ctrl+Shift+Left` 等单键和组合，每次触发发送一次完整按下与释放。发送在独立后台队列执行，前台窗口切换则取消，自身注入不再次触发。配置和 CapsLock 导航示例见[发送按键与快捷键](KEYBOARD_ACTIONS.md)。
- “本地步骤动作”可在触发器和轮盘中组合快捷键、单独 Alt 点按、整组保持修饰键的按键序列、Unicode 文字、文本剪贴板、变量、打开目标和等待。动作库提供能力入口，小表单支持添加、排序与编辑步骤；保存不执行，测试会真实运行。失败或取消停止后续步骤，已经完成的操作不会回滚。配置与执行边界见[本地步骤动作](LOCAL_ACTIONS.md)。
- 动作仍可选择“仅提示”“触发面板”或“运行程序”。程序动作填写路径、参数数组及可选工作目录；解释器可用于运行 PowerShell、Node 等脚本。
- “窗口操作”独立提供原生最大化 / 恢复和最小化，由后台线程在提交前核验原窗口仍有效且为前台。“外部动作”独立保存依赖名称和绝对程序路径，依赖缺失时不可用，启动前检查前台；交给外部进程后无法强制约束其最终操作目标，进程退出也不代表外部业务完成。
- “测试动作”真实运行当前草稿中的程序，不必先保存，不计入命中次数。“测试提示”仍只显示文字。外部命令由后台执行，同一绑定运行期间拒绝重复启动，总计最多 4 个任务；启动失败、非零退出码和忙碌拒绝会显示在界面与动作执行记录中。
- 侧栏可暂停/恢复全部监听；暂停或监听断开时列表变暗并显示提示条。
- “触发记录”保留本次运行最近 30 条，可按组合触发、面板 / 轮盘选择与测试提示筛选；面板和轮盘执行合并计数，记录区分来源，不计入组合命中次数。
- 自动保存到 `%LOCALAPPDATA%\OmniTrigger\bindings.json`。初次运行加载示例，之后保留用户配置。

“测试提示”只验证消息显示，不计入命中次数；命中统计与记录只在本次运行期间保留。提示消息输入框为单行。程序退出后移除监听。
