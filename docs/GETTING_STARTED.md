# 快速开始

本页介绍如何下载 Windows 预览版、完成第一次试用并录制自己的组合。项目处于 `0.1.0` 早期开发阶段，API 与配置格式可能调整；从源码运行见[从源码构建](BUILDING.md)。

## 系统要求

- Windows x64，建议使用 Windows 11；Windows 10 尚未完成全面兼容验证。
- [Microsoft Visual C++ v14 Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。如提示缺少 `VCRUNTIME140.dll`，请安装微软官方运行库。
- 以普通权限运行，无需安装驱动，也无需 Rust 或开发工具。

## 下载与核验

从 [Releases](https://github.com/ceastld/omnitrigger/releases) 下载 `OmniTrigger-<版本>-windows-x86_64.zip`，完整解压后运行 `omnitrigger.exe`。当前只提供 Windows x64 包。发布包包含项目及依赖许可，旁附 `SHA256SUMS.txt` 供核验下载完整性：

```powershell
Get-FileHash .\OmniTrigger-0.1.0-windows-x86_64.zip -Algorithm SHA256
```

程序未经代码签名，不提供安装器、系统托盘或自动更新。主窗口负责配置管理，关闭主窗口会退出应用。

## 第一次试用

没有已有配置时，首次启动加载示例绑定并开始监听：

| 组合 | 动作 |
| --- | --- |
| `CapsLock + W` | 显示提示 |
| `鼠标侧键 1 + 滚轮上滚` / `滚轮下滚` | 显示提示 |
| `CapsLock + Space` | 显示或收起浮动触发面板 |
| 右键长按 `300ms` | 在当前鼠标位置显示触发面板 |

建议按以下顺序试用：

1. 先按住 `CapsLock` 再按 `W`，松开后确认屏幕右下角的提示浮层，以及列表中的命中次数。
2. 按住鼠标侧键 1 并滚动滚轮。
3. 单独按下并松开 `CapsLock`。未组成组合的前缀会回放原输入；延迟与补发会改变时序，不能承诺完全无损。
4. 按 `CapsLock + Space`，或按住右键约 300ms 打开触发面板。按 `Esc`、点击面板以外的位置或关闭按钮收起。

## 录制自己的组合

1. 在“触发器”页点击“录制组合”，按住前缀，再按目标键或滚动滚轮，全部松开后完成录制。录制期间实时显示已按住的键，`Esc` 取消。录制会拦截全部输入，鼠标点击也会被录下。
2. 录完立即按注册规则检查：与已有组合重复、目标键与其他组合的前缀冲突等情况会指出冲突的触发器，不覆盖原有绑定。
3. 选择触发方式（按下即触发、长按或快速拖拽）、可选的鼠标位置条件和动作，再点击“添加触发器”。

不想从录制开始时，可在侧栏“触发预设”选择 23 个可编辑模板之一，例如右键快速拖拽、屏幕边缘滚轮或右键长按。选择预设只填写草稿，保存后才生效，详见[触发预设](TRIGGER_PRESETS.md)。

| 想要实现 | 参考 |
| --- | --- |
| 触发后发送快捷键或方向键 | [发送按键与快捷键](KEYBOARD_ACTIONS.md) |
| 组合按键、文字、剪贴板与等待 | [本地步骤动作](LOCAL_ACTIONS.md) |
| 运行程序或脚本 | [程序与脚本](COMMAND_ACTIONS.md) |
| 用 JS 组合多步骤程序调用并复用参数 | [动作包与 JavaScript 入口](ACTION_PACKAGES.md) |
| 在屏幕边缘滚动调节音量或亮度 | [鼠标区域与系统调节](POINTER_REGIONS.md) |
| 右键快拖呼出动作轮盘 | [自定义轮盘](RADIAL_WHEELS.md) |
| 从浮动面板点选动作 | [浮动触发面板](TRIGGER_PANEL.md) |

边缘滚轮示例中，左右边缘每格调节鼠标所在屏幕亮度 5 个百分点，并显示本软件的目标屏幕亮度浮层；上边缘每格发送一次系统音量增加或减少键，由 Windows 决定步长并显示原生音量浮层，其位置也由 Windows 选择。亮度浮层只响应 OmniTrigger 的动作回执，不监控其他软件的调节。

## 安装截图插件

1. 打开侧栏“扩展”页，点击 RaiShot 的“启用”。程序先查找本机已有的 RaiShot（包括正在运行的副本和 Quicker 包目录），找到即直接使用；找不到时才下载固定版本 `0.4.15` 及运行依赖，成功后保存 CLI 路径。准备过程不启动截图，也不注册快捷键。
2. 在截图卡片点击“设置触发”，默认填入 `左 Ctrl + 左 Alt + A`。这是 OmniTrigger 适配提供的默认组合，可点击“重新录制”录制自己的组合，或“选择预设”改用长按、侧键等方式。
3. 点击“添加触发器”；编辑已有绑定时点击“保存动作”。“恢复默认”只修改当前草稿，仍需保存并通过冲突检查，不覆盖其他组合。
4. 使用组合触发截图，或从浮动面板点击动作。“测试动作”会真实启动当前截图动作；进程正常退出也可能是取消截图，不能据此认定已经生成图片。

已有 RaiShot 时不会再下载副本：接入 0.4.15 至 0.5 之前的最高兼容版本，原安装文件保持原位，也不扫描整个电脑。原路径失效时，启动或刷新会自动改用本机其他兼容安装。“扩展”页提供刷新和停用；缺失程序、停用插件或不兼容动作会保留绑定并标记不可用，同时移出实际监听注册集。多个截图绑定与测试入口共享单并发，忙碌时拒绝新调用。

如果需要下载，安装器访问 [RaiShot v0.4.15 发布包](https://github.com/ceastld/raishot/releases/tag/v0.4.15)，先尝试匿名 HTTPS；匿名下载不可用时，安装器尝试使用本机已安装、已登录且有仓库权限的 GitHub CLI（`gh`），不会自动安装或登录 `gh`。无权限时显示安装错误；修复访问权限后可重试。非标准位置的已有安装可通过[开发排障配置](PLUGIN_SYSTEM.md#开发排障入口)指定。

下载包包含截图所需程序、DLL 和许可文件；安装器校验 ZIP 的 SHA-256 及包内文件后再启用，失败保留原设置，不自动重试。下载的运行文件位于 `%LOCALAPPDATA%\Programs\RaiShot\0.4.15`，其他程序也可复用；复用的安装保留原位置。新下载的程序首次截图时 Windows 会进行安全检查，可能需要约 1 分钟，之后启动明显更快。RaiShot 保留其 GPL-3.0-or-later 及随包第三方许可，详见[第三方说明](../THIRD_PARTY_NOTICES.md)。开发者可提供本地 RaiShot 动作清单，当前不提供通用插件导入界面、插件市场或自动更新；格式与扩展边界见[插件动作与快速绑定](PLUGIN_SYSTEM.md)。

## 命令行参数

| 参数 | 作用 |
| --- | --- |
| `--config <文件路径>` | 使用独立配置文件，后续编辑保存到该文件；插件设置和下载目录也位于所选文件的目录，适合隔离试用。 |
| `--check-config` | 检查所选配置的格式、动作参数、组合冲突、同目录轮盘配置及轮盘引用，不安装 Hook，也不执行动作。 |
| `--preview-system-hud brightness\|volume` | 预览本软件自有浮层外观约 30 秒，可带 `--percent 0–100`、`--point x,y`；`volume` 也仅为外观预览，不安装 Hook 或读取、写入硬件数值。 |
| `--check-action <调用文件>` | 只读检查动作包调用结构、包身份和契约版本，不执行 JS 或安装 Hook。 |
| `--run-action <调用文件>` | 真实执行动作包调用并返回结构化结果，不安装 Hook。调用文件形态见[动作包说明](ACTION_PACKAGES.md)。 |
| `--panel` | 启动后直接显示浮动触发面板。 |
| `--wheel-editor` | 打开轮盘管理页。 |
| `--wheel <轮盘标识>` | 显示指定轮盘并等待选择，例如 `--wheel orbit-edit`。 |
| `--smoke-test` | 安装并卸载真实 Hook 后退出，需要交互式 Windows 桌面。 |

参数可以与 `--config` 组合，例如先检查、再隔离试用一份独立配置：

```powershell
.\omnitrigger.exe --config D:\OmniTrigger-demo\bindings.json --check-config
.\omnitrigger.exe --config D:\OmniTrigger-demo\bindings.json
```

发布包不包含示例配置。可从仓库的 [`examples/`](../examples/) 下载 JSON 示例，复制到独立目录后用上述命令检查和试用。

配置文件位置、备份与隐私说明见[配置文件与隐私](CONFIGURATION.md)。监听偶发失效或与其他输入工具并用时，见[并用其他工具与诊断](TROUBLESHOOTING.md)。
