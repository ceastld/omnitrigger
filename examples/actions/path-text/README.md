# 显式路径文本

对调用参数中的 `paths` 做纯文本变换，提供 Node 异步与轻量同步 ESM 入口。不读取 Explorer、剪贴板、选区或磁盘，不检查路径是否存在、是否为文件或目录，也不解析链接。

`operation` 必须明确指定：

| 值 | 结果规则 |
| --- | --- |
| `name` | 取最后一段名称，保留扩展名。根目录没有名称，报 `path_name_missing`。 |
| `stem` | 取名称并去掉最后一个扩展名；`.env` 保留，`a.tar.gz` 得到 `a.tar`。 |
| `parent` | 删除最后一段；盘符根目录的父目录仍为自身。不根据末尾分隔符猜测文件类型。 |

只接受本地盘符绝对路径，斜杠统一为反斜杠，可有一个末尾分隔符。拒绝 UNC、设备路径、相对路径、`.` / `..`、空中间段、ADS 冒号、Windows 名称禁用字符及末尾空格/点。这里只限定文本语法，不证明名称能被 Windows 创建或访问；不补全环境变量、不进行大小写或 Unicode 归一化、不加 Shell 引号。

输入为 1–128 条路径，总计最多 65,536 个 UTF-16 单元，有效 Unicode、无控制字符；输出按原顺序保留重复项，用 LF 连接，也不超过 65,536 个 UTF-16 单元。`paths` 数组中的空洞、额外属性，以及输入对象的未知字段均拒绝。

- `mode:"inspect"`：完成变换与校验，只返回数量和长度，没有宿主调用。
- `mode:"send"`：先完整变换，再向提交时捕获的原目标 `sendText` 一次。终态只返回摘要，不含路径或输出；失败/失焦/取消不重试，不用剪贴板回退。

默认两份调用均为 inspect。实际 send 会输入文本；`inputSubmitted:true` 只代表系统接纳输入，不能证明业务完成，也不能撤销已发生的部分输入。两个动作分别启用单实例，不互锁。这是独立路径变换包，不提供文件菜单、文件操作或自动路径采集。

```powershell
node --test examples/actions/path-text/recipes.test.mjs
```

测试仅使用合成路径和 RecordingHost，不创建或读取对应文件。
