# 原目标窗口操作菜单

将现有 `ctx.ui.choose` 和 `ctx.desktop.windowAction` 组合为一个明确的主操作：选择后，对提交时捕获的原窗口执行最小化、切换最大化或关闭。没有快捷键猜测，不枚举其它窗口，也不重新捕获前台。

输入必须是空对象 `{}`。Node 入口 `choose` 与轻量同步模块入口 `choose-script` 共用 `menu.mjs`，均为版本 1。两者分别启用动作级单实例，两个动作 ID 不互锁。

关闭/超时不提交窗口操作；未知选择、取消、失焦、目标失效或宿主错误均停止，不重试、不回退键盘快捷键。选择框的焦点恢复和原目标检查由宿主完成。关闭可能出现保存提示；`submitted:true` 只表示系统接纳请求，不表示窗口已经关闭或业务成功。

此配方只操作原目标，没有其它窗口行的身份切换、置顶、透明度、结束进程、资源管理器查询或文件操作。它不读取剪贴板、不调用历史服务、不启动后台监听。错误消息固定，终态只返回选择的操作及提交状态。

```powershell
node --test examples/actions/target-window-menu/recipes.test.mjs
```

测试只调用内存 RecordingHost。真实应用选择框、取消与窗口操作须另行验收；包清单和源码就绪不代表已启用个人绑定。
