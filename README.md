![OmniTrigger 触发器管理界面：触发器列表、组合键帽与触发器详情](site/public/screenshots/triggers.webp)

录下一个操作，就能将其注册为触发器，例如 `CapsLock + W`、`鼠标侧键 + 滚轮上滚`。当前提供 Windows 桌面测试程序，触发后显示本地提示、发送快捷键、运行程序或脚本，也可呼出自定义动作轮盘；还可在“扩展”页一键启用 RaiShot，自动复用兼容的已有安装或下载依赖，再选择截图动作并设置触发。

当前为 Windows x64 开发预览版，API 与配置格式可能调整。v0.2.1 提供当前用户安装器和独立的本机测试配置档，日常窗口的设置页支持检查更新、后台下载并重启更新。

## 当前状态

当前提供 Windows + GPUI 桌面测试程序，核心引擎可独立测试，主要能力包括：

- **统一触发描述**：键鼠组合、长按、快速拖拽、鼠标手势与鼠标区域条件共用 `TriggerSpec`，录制、注册与运行时匹配采用同一套规则；边缘支持起止缩进，可同时配置左右边缘亮度与上边缘音量，并排除多屏连接处。
- **动作执行**：本地提示、发送快捷键、本地步骤、窗口操作、音量 / 亮度调节、外部程序及可选截图插件。
- **动作包扩展**：统一动作引用与运行时接口，支持本地 JavaScript 动作包、JSON 输入、多步骤程序调用和结构化执行结果；Node.js 需单独安装。
- **浏览器动作**：安装连接器后，在动作库选择“浏览器操作”，可绑定标签页管理、前进后退、恢复关闭和新建窗口，也可直接调用 Chrome API；后台复用持久连接，无需 Node.js。
- **桌面界面**：触发器管理、23 个可编辑预设、浮动触发面板、多轮盘与按应用选择槽位；亮度提示由独立 Win32 窗口显示紧凑横条，滚动时立即反馈请求目标，后台结果静默校正，只响应本软件动作，不等待 GPUI 绘制。上边缘音量示例发送系统音量键，步长和原生音量浮层的位置由 Windows 决定。
- **快速搜索**可用工作台内的 `Ctrl+K` 打开。搜索页面名称、触发器名称或 `CapsLock+W` 等组合，用上下方向键选择并回车打开。以 `触发器:` 开头可只搜索触发器。输入 `2**10`、`sqrt(2)`、`sin(radians(90))`、`10 km to mi` 或 `1 GiB to MiB` 可计算和换算，按回车复制结果。三角函数使用弧度，数据单位的 `B` 表示字节，`b` 表示比特。
- 输入 `10 km to mi` 或 `0xff to dec` 得到结果后，可按 `Tab` 回到目标候选并重选单位或进制。
- 输入 `批量换算:` 后逐行写入换算式，例如 `3 m to cm`、`0xff to dec` 和 `1 GiB to MiB`。结果按行返回 `300 cm`、`255` 和 `1024 MiB`，可一次复制。遇到无法换算的行会显示行号和原因。
- 用 `批量换算: 对照` 逐行写入单位或进制换算式，可导出“输入”和“结果”两列 CSV。有误时会显示原输入的行号。
- 用 `批量换算: 时长` 逐行填写时长换算，例如 `01:30 to s` 和 `PT1M30S to min` 分别得到 `90 s` 和 `1.5 min`。不同的时长写法可在同一批混用。
- 用 `批量换算: 时长对照` 逐行输入时长算式，可导出“输入”和“结果”两列 CSV。可以混用时刻区间、扣除休息和单位换算。有误时会显示原输入的行号。
- 用 `批量换算: 时间戳` 逐行换算 Unix 时间戳和带时区的日期时间。每行可指定不同的单位或时区。同一批中的 `现在` 使用同一参考时刻。
- 用 `批量换算: 时间戳对照` 可导出“输入”和“结果”两列 CSV。同一批中的 `现在` 使用同一参考时刻，遇到无法换算的输入会显示行号。
- 用 `批量换算: 路径` 逐行填写路径操作，例如 `文件名 "C:\工作\报告 集.txt"` 和 `转文件网址 C:\docs\report 2026.txt`。每行可选择不同的操作，结果按顺序返回。
- 用 `批量换算: 网址` 逐行填写 URL 操作，例如 `去查询串 https://example.invalid/doc?q=a#part` 和 `表单解码 a%2Bb+c`。每行可选择不同的操作，结果按顺序返回。输入有误时会指出行号。
- 用 `批量换算: 路径对照` 或 `批量换算: 网址对照` 可将对应操作的原输入和结果导出为两列 CSV。每行可用不同的操作，有误时会指出行号。
- 用 `批量换算: 颜色` 可逐行将 HEX、RGB、HSL、HWB 或 CSS 颜色名换算成 HEX，保留输入指定的透明度。用 `批量换算: 颜色对照` 可导出原输入和结果两列 CSV。
- 用 `批量换算: 进制对照` 可逐行填写进制或字节序操作，例如 `ff 从 16 到 10`、`字节序 16 @ 258` 和 `读字节序 小端 @ 02 01`。结果以 CSV 输出，字节序的多行结果保存在同一个单元格，遇到错误会指出原输入的行号。
- 用 `批量换算: 日期` 逐行计算日期，例如 `2026-11-20 + 1工作日` 和 `2027-01-01 第几周`。同一批的 `今天` 使用同一系统本地日期，输入有误时会指出行号。
- 用 `批量换算: 日期对照` 逐行输入日期算式，可导出“输入”和“结果”两列 CSV。同一批仍采用同一个本地日期，有误时会显示原输入的行号。
- 输入 `批量计算:` 后逐行写入算式，例如 `2**8`、`3^3` 和 `sqrt(81)`。结果按行返回 `256`、`27` 和 `9`。算式出错时会显示对应行号。
- 用 `批量计算: 分数` 逐行填写精确算式，`1/3 + 1/6` 和 `2**80` 分别得到 `1/2` 和 `1208925819614629174706176`。
- 用 `批量计算: 对照` 或 `批量计算: 分数对照` 逐行填写算式，可输出“算式”和“结果”两列 CSV。结果沿用输入顺序，保留算式写法，出错时显示对应行号。
- 用 `处理: ["文本: 去空行","CSV: 数值对象 [2]","JSON: 取值 /1/金额"]` 加上 CSV，可先清理空行，再将第二列转换为 JSON 数字，最后取出第二条记录的金额。支持 1 至 8 条单行命令，前一步的结果会传给下一步，有误时显示步骤编号。 输入 `处理:` 可查看内置示例。按 `Shift+Tab` 会保留步骤并选中示例数据，直接输入或粘贴可替换数据。
- `处理:` 也可串联 URL、路径和日期命令。输入 `处理: ["日期: 月末序列","文本: 按行拼接 \", \""] 2024-01,3`，可把三个月底拼到一行。一次处理里的日期命令共用同一个本地日期。
- 用 `处理: 步骤CSV ["文本: 大写","文本: 小写"] Tea` 可导出每一步的序号、命令和结果，依次看到 `TEA` 和 `tea`。多行结果保存在一个单元格，处理失败时会显示出错步骤。
- `处理: ["CSV: 选列 2","文本: 间隔取行 2,1","统计: 分位数 50%"]` 加上含表头的 CSV，可读取第二列的数值并求中位数。处理步骤也可使用 `分数: 计算`，用精确分数继续计算。
- 输入 `已启用触发器`、`已停用触发器`、`全局触发器` 或 `指定应用触发器` 可直接查看对应列表。加冒号后可再输入名称、组合或应用名。结果会显示绑定的应用范围和场景。
- 页面、触发器和动作等匹配项超过一页时，用 `PageUp`、`PageDown` 或点击页码旁的按钮翻页。方向键也可连续选择跨页的结果。
- 用 `Ctrl+PageUp` 和 `Ctrl+PageDown` 可跳到第一页或最后一页。用法列表、匹配项和展开的计算结果都可使用。
- 输入 `?` 可浏览全部用法，按 `Page Up` 或 `Page Down` 翻页。输入 `? 时长` 可按关键词查找示例，标题或命令以关键词开头的示例优先显示。关键词接受全角字母、数字和标点。用方向键选择示例并回车即可填入。
- 搜索框内按 `F1` 可打开用法列表并暂存当前输入。输入查询后，也可点击右上角的「用法 F1」。在 `CSV:`、`JSON:` 或 `日期:` 等工具中，列表会先显示当前工具的用法。筛选示例时再次按 `F1` 或点击「返回查询 F1」可恢复原来的输入。
- 输入框为空时点击右上角的「工具」，或输入 `工具:`，即可浏览工具目录。每个工具显示一条示例，继续输入关键词可筛选，例如 `工具: 叉积`。选中后按回车或 `Tab` 填入示例，按 `F1` 查看这个工具的更多用法，再按 `F1` 返回目录筛选。
- 输入 `用法历史:` 可找回本次运行中通过回车、Tab 或点击填入的最近 12 条示例。继续输入关键词可按示例名称或内容筛选，选中后按 Tab 可再次填入。
- 可直接输入 `计算器`、`字数` 或 `分数` 查找对应示例，回车就能填入。
- 输入函数名开头或刚输入左括号时，可直接选常用算式。例如输入 `sqr` 或 `sqrt(` 后按 `Tab` 可填入 `sqrt(2)`。
- 算术结果可按 `Tab` 填回输入框。输入 `1-4` 后按 `Tab`，再输入 `**2` 可继续算得 `9`。
- 搜索得到结果后，按 `F3` 或点「填回结果」可将完整结果放入输入框，光标停在开头，可直接添加下一条工具命令。编辑前再次按 `F3` 可恢复原查询。超过 4096 个字符的结果可用回车复制。
- 选中示例、历史算式或换算候选时，可按 `Tab` 或回车填回输入框。
- 在 `JSON:`、`TOML:`、`CSV:`、`文本:`、`URL:`、`路径:`、`UUID:` 和 `ULID:` 的用法列表中，按 `Shift+Tab` 可填入选中的命令并选中示例参数。日期、时长和进制工具中带有命令名的示例也可用这个快捷键。直接输入或粘贴即可替换参数，命令名会保留。
- 输入 `算式历史:` 或在搜索框按 `Ctrl+R`，可找回本次运行中最近复制或用于续算的 12 条算式。`Ctrl+R` 会以当前输入作为初始筛选词。可修改筛选词，再按 `Ctrl+R` 可恢复打开历史前的完整输入。用 `PageUp`、`PageDown` 查看各页，按回车填回所选算式。
- 输入 `换算历史:` 可查找本次运行中最近复制的 12 条单位或进制换算，也可继续输入单位或结果筛选。支持翻页，两种历史的筛选词均接受全角字母、数字和标点。
- 在新打开的搜索框按 `Ctrl+Shift+R`，可填回之前搜索框里的最后一项非空输入。本次应用运行期间可用。
- 搜索框内按 `Ctrl+D` 可收藏当前查询，再按一次可取消。输入框为空时按 `Ctrl+D` 可打开收藏列表，也可输入 `收藏:` 后按关键词筛选。按 `Tab` 或回车填回所选查询，在列表中按 `Ctrl+D` 移除所选项。当前配置最多保存 12 项，保留多行和空格，重新启动后可继续使用。
- 在收藏列表选中查询后按 `F2` 可命名，按回车保存，按 `Esc` 返回。名称会随收藏保存，`收藏:` 后可用名称或原查询中的关键词筛选。清空名称并保存可恢复显示原查询。
- 在收藏列表用 `Alt+↑` 或 `Alt+↓` 可移动当前选中项。筛选时交换相邻的可见项，移动后的顺序会随当前配置保存。
- 在搜索框按 `F4` 可打开收藏列表。在列表内筛选后再次按 `F4`，可回到打开收藏前的完整输入。
- 从收藏列表用 `F1` 打开用法后，可按 `F4` 回到收藏筛选。再次按 `F4` 可回到打开收藏前的查询。
- 在快速搜索输入 `剪贴板: 关键词` 并回车可打开文本历史并查找已保存文本的正文。
- 输入 `触发记录: CapsLock+W` 可在最近 30 条触发记录中查找组合，也可按提示文字筛选。留空关键词可查看全部记录。
- 输入 `动作: 浏览器` 可打开动作库并填入筛选词。动作包和插件动作也会按名称出现在快速搜索结果中，回车可在动作库中查看。只输入 `动作:` 可清空筛选。
- 输入 `应用:` 后加应用名可从 Windows 应用目录查找程序。用方向键选择，按回车启动。也可用 `app:`。 [Windows 应用目录](https://learn.microsoft.com/windows/win32/shell/knownfolderid)
- 在 `应用:` 搜索中按 `F5` 可重新读取 Windows 应用目录，沿用当前关键词和仍存在的选中项。
- 直接输入两个字符以上的应用名也可查找程序。快速搜索会先匹配工作台内容和工具，再从 Windows 应用目录查找。
- 应用名称中的英文单词也可用首字母检索，例如 `应用: vsc` 查找 Visual Studio Code。名称和应用标识中的直接匹配会优先显示。
- 可把一组首字母与名称关键词一起用，例如 `应用: vs code`。首字母按名称中的英文单词顺序匹配，其他词可以匹配名称或应用标识。支持大小写和全角英文字母。
- 输入 `系统设置: 蓝牙` 可查找并打开 Windows 的蓝牙设置。用 `系统设置:` 可浏览显示、声音、通知、存储、默认应用等常用页面，方向键选择后按回车打开。 [Microsoft 的 Windows 设置页面地址](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)
- 输入 `文件夹:` 可浏览桌面、下载、文档、图片、音乐和视频。也可用 `文件夹: 下载` 或 `folder: downloads` 筛选，按回车打开选中的文件夹。 [Windows 已知文件夹](https://learn.microsoft.com/windows/win32/shell/knownfolderid)
- 在文件夹搜索中选中一个文件夹后按 `Tab`，可把 Windows 当前配置的路径填入文件搜索。再次按 `Tab` 可浏览目录，也可以先填写 `| 文件名` 缩小范围。 [Windows 已知文件夹路径](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shgetknownfolderpath)
- 输入 `文件: C:\工作 | 报告` 可在指定本地目录的直接子项中按名称查找。按回车复制所选项的完整路径。分隔符后的名称可留空，多个关键词用空格隔开。匹配本地固定卷上的普通文件和文件夹。
- 也可先输入 `文件: C:\工作`，按 `Tab` 即可浏览该目录。搜索框会自动补上分隔符，再继续输入名称即可筛选。
- 在文件搜索中选中文件夹后按 `Tab` 可进入该文件夹，按 `Alt+↑` 可回到上一级。也可用 `文件: C:\工作 | *.pdf` 或 `报告?.docx` 按 Windows 文件名通配规则匹配。 [Windows 文件名通配规则](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-findfirstfilew)
- 通过 `Tab` 或 `Alt+↑` 切换文件夹后，可在同一个搜索框用 `Alt+←` 返回、用 `Alt+→` 前进。返回时恢复原查询的名称筛选、排序和输出选项。
- 找到文件后可按 `Alt+Enter` 或点选中行的「定位」，在资源管理器中选中该文件或文件夹。
- 在文件搜索中按 `F5` 可用当前目录与筛选条件重新读取结果。读取期间保留列表，原选中项仍存在时继续选中它。
- 输入 `文件: C:\工作 | *.pdf | 最近修改` 可把匹配项按最后修改时间从新到旧排列。可留空中间的名称条件，修改时间相同的按名称排列。 [Windows 目录项的最后修改时间](https://learn.microsoft.com/en-us/windows/win32/api/minwinbase/ns-minwinbase-win32_find_dataw)
- 输入 `文件: C:\工作 | *.pdf | 最近创建` 可按创建时间从新到旧排列。创建时间相同的按名称排列，缺少创建时间的项排在最后。 [Windows 目录项的创建时间](https://learn.microsoft.com/en-us/windows/win32/api/minwinbase/ns-minwinbase-win32_find_dataw#members)
- 输入 `文件: C:\工作 | *.pdf | 大小` 可把匹配文件按字节数从大到小排列，并在每个文件下方显示字节数。同样大小的文件按名称排列，匹配的文件夹排在文件之后。 [Windows 目录项的文件大小](https://learn.microsoft.com/en-us/windows/win32/api/minwinbase/ns-minwinbase-win32_find_dataw#members)

- 用 `CSV: JSON展开行 ["商品","数据","/商品"]` 可把数组元素依次添加到新列，每个元素一行，原列随行保留。空数组、空单元格、缺少的路径和 `null` 保留一行并把新列留空。结果最多 1 MiB。
- 用 `CSV: 时刻差列 ["经过时长","开始","结束"]` 可给表格追加每行两个钟表时刻的间隔。支持时分、时分秒及小数秒。结束时刻更早时按跨午夜计算，从 `23:45` 到 `01:15` 得到 `01:30:00`。任一时刻为空时新列留空。
- 用 `CSV: 累计合计列 ["累计金额","金额",["部门"]]` 加上含表头的 CSV，可按原行序为每个部门追加累计金额。用 `累计平均列` 可求累计平均。第三项填写分组列，用 `[]` 可按整列累计。结果保留精确分数。空金额沿用当前累计，同组尚无数据时合计填 `0`，平均留空。
- 用 `CSV: 差分列 ["变化","金额",["部门"]]` 可按原行序给每组追加数值变化。每个非空金额减去同组上一个非空金额，首项和空金额行留空。用 `[]` 可按整列计算，结果保留精确分数。
- 用 `CSV: 变化率列 ["变化率","金额",["部门"]]` 可把同组两个相邻非空金额的差除以上一个金额。从 `1/3` 增至 `0.5` 得到 `1/2`，表示增加 50%。用 `[]` 可按整列计算。首项和空金额行留空，上一个金额为零时会指出当前行。
- 用 `CSV: 移动平均列 ["近两笔","金额",["部门"],2]` 可求每个部门最近两个非空金额的平均值。用 `移动合计列` 可求窗口内合计。窗口支持 1 至 128 项，空值行和窗口尚未填满的行留空。分组列用 `[]` 可按整列计算，结果保留精确分数。
- 用 `CSV: 移动分位数列 ["P25","金额",["部门"],2,"25%"]` 可逐行计算每组最近两个非空金额的 25% 分位数。窗口支持 1 至 128 项，空值行和未填满的窗口留空。分组填 `[]` 时按整列计算，概率可写成分数、小数或百分数。 [R 的 Type 7 分位数定义](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/quantile.html#types)
- 用 `CSV: 排名列 ["名次","金额",["部门"]]` 可按组从大到小排名，`升序排名列` 改为从小到大。等值并列，后续名次保留跳号，例如 `1,2,2,4`。可用 `[]` 按整列排名。输出保留原行顺序，空值行留空。 [R 的并列排名规则](https://stat.ethz.ch/R-manual/R-devel/library/base/html/rank.html)
- 用 `CSV: 密集排名列 ["名次","金额",["部门"]]` 可对每组不同的数值依次编号。相同数值并列，后续名次紧接上一名，例如 `1,2,2,3`。用 `升序密集排名列` 从小到大排名。 [PostgreSQL 的密集排名规则](https://www.postgresql.org/docs/current/functions-window.html)
- 用 `CSV: 前值列 ["上期","编号",1,["部门"]]` 可从本组前一行取值，用 `后值列` 可从本组后一行取值。第三项填写正整数行距，分组用 `[]` 时按整表处理。按原表顺序定位，超出本组范围或取到空单元格时，结果留空。
- 用 `CSV: 占比列 ["占比","金额",["部门"]]` 可按组把每行金额除以该组的合计，结果保留精确分数。例如同一部门金额为 `2` 和 `6`，占比分别为 `1/4` 和 `3/4`。分组列用 `[]` 可按整列计算，空金额留空，组内合计为零时提示相应行。
- 用 `CSV: 组内计数列 ["记录数",["部门","月份"]]` 可在每行追加同组的总记录数。用 `组内序号列` 则为每组从 1 开始编号。两种操作均保留原行顺序，空单元格参与分组，分组列填 `[]` 时整张表为一组。
- 用 `CSV: 连续分组列 ["分组",["部门"]]` 可给相邻且同部门的一段记录加上同一个编号。遇到部门变化时开始下一段。`段内序号列` 可在每段内从 1 开始编号，支持按多个列组合分段。
- 用 `CSV: 常量列 ["来源","人工,复核"]` 加上含表头的 CSV，可在表尾追加“来源”列，并填入相同的文本。列名须非空且未被使用，值可以为空，结果最多 1 MiB。
- 用 `CSV: 加行号 ["序号",100]` 可在表尾追加自 100 起的连续行号。起点可填 0 或正整数，带引号的跨行字段所属记录只计一次。
- 用 `CSV: 拼接列 ["地址",["省",3],"-"]` 加上含表头的 CSV，可逐行把“省”和第三列拼接为“地址”。可混用列名和列号，空单元格照常参与拼接。结果保留原列，最多 1 MiB。
- 用 `CSV: 首个非空 ["联系",["手机","座机"]]` 可按候选列顺序逐行取第一个非空值，写入新列。只跳过空字符串，候选都为空时新值留空，原列会保留。
- 用 `CSV: 正则提取列 ["省份","地址","^(?P<province>[^省]+)省","province"]` 可从每行地址的第一个匹配取指定捕获组。最后一项把组名或编号写在双引号内，`"0"` 表示整个匹配。没有匹配或该组未出现时，新列留空。 [正则捕获组说明](https://docs.rs/regex/latest/regex/#example-named-capture-groups)
- 用 `CSV: 拆分列 ["地址",["省","市和区"],"/"]` 加上含表头的 CSV，可保留原表，在末尾逐行追加拆分后的列。来源可用列名或列号，新列名须互不重复。额外分段保留在最后一列，缺少的分段填空，结果最多 1 MiB。
- 计算列也可按表头名称引用，例如 `CSV: 计算列 ["金额","数量","*","单价"]`。表头名称必须精确匹配且唯一，列名和列号可以混用。
- 用 `CSV: 公式列 ["含费金额","数量",3,"x*y+1/6"]` 加上含表头的 CSV，可将数量代入 `x`、第三列代入 `y`，在表尾追加精确结果。列名和列号可以混用，每次最多处理 32 条数据。
- 只用一列时可写 `CSV: 公式列 ["平方","数量","x**2"]`。每行将“数量”的值代入 `x`，再追加结果，例如 `1/3` 得到 `1/9`。
- 用 `CSV: 数值比较列 ["达标","实测",2,">="]` 可逐行比较“实测”和第二列，追加 `true` 或 `false`。比较支持分数、小数和科学计数法，任一单元格为空时留空。无效数值会标明数据行。
- 用 `CSV: 离群列 ["离群","金额"]` 可按整列有效数值计算箱线图的内围栏。严格超出围栏的行标记 `true`，其余数值标记 `false`，空单元格跳过。 [NIST 内围栏规则](https://itl.nist.gov/div898/handbook/prc/section1/prc16.htm)
- 输入 `CSV: 去重` 后粘贴表格，按每一列的单元格内容比较，保留相同行首次出现的位置。单元格中的空格参与比较。
- 输入 `CSV: 按列去重 1,2` 后粘贴含表头的表格，可按第一列和第二列的组合去重。结果保留表头和每个组合首次出现的整行。
- 用 `CSV: 查重复 ["编号",2]` 可找出所选列组合重复的所有记录，包括每组的第一条。列名与列号可以混用，按原单元格文本比较，结果保留表头和原行顺序。没有重复时只输出表头。
- 用 `CSV: 数值去重 ["金额"]` 可按精确数值比较选中的列，例如把 `1.50`、`3/2` 和 `1.5e0` 视为同一个值。支持列名和列号，保留每组首次出现的整行及原数字写法。所选列需要有效数字。
- 用 `CSV: 数值查重复 ["金额"]` 可找出按精确数值重复的所有记录，沿用原行顺序和数字写法。所选列均须为有效数字。
- 输入 `CSV: 筛选 2 "完成"` 后粘贴含表头的表格，可保留第二列内容恰好为“完成”的行。用 `排除` 可跳过这些行。匹配区分大小写与空格，用 `""` 匹配空单元格。
- 输入 `CSV: 正则筛选 2 "^咖啡"` 后粘贴含表头的表格，可保留第二列以“咖啡”开头的整行。用 `正则排除` 可去掉这些行。表达式用 JSON 字符串书写，例如用 `"^\\d+$"` 匹配纯数字。
- 输入 `CSV: 数值筛选 2 >= 3/2` 后粘贴含表头的表格，可保留第二列数值大于等于 `3/2` 的整行。支持 `<`、`<=`、`=`、`!=`、`>=`、`>`，按精确数值比较并保留单元格的原始写法。
- CSV 筛选或排除也可用双引号包住表头名称来选列，例如 `CSV: 数值筛选 "价格" >= 3/2`。普通筛选、正则筛选和数值筛选都要求列名精确匹配且唯一。
- 用 `CSV: 多条件筛选 [["状态","文本=","完成"],[3,">=","3/2"]]` 加上表格，可保留同时满足各条件的记录。换用 `任一条件筛选` 可保留满足至少一条条件的记录。最多 16 条，可用列名或列号，比较值写在双引号内。支持 `文本=`、`文本!=`、`正则`、`正则排除` 和精确数值比较符。所有被比较的数值列均须有有效数字。
- 输入 `CSV: 分组计数 2,1` 后粘贴含表头的表格，可统计第二列和第一列的每种组合出现几次。结果按组合首次出现的顺序输出，并在最后一列附上计数。
- 输入 `CSV: 分组合计 2,1 3` 后粘贴含表头的表格，可按第二列与第一列的组合，对第三列求精确合计。输出沿用组合首次出现的顺序，数值列支持整数、小数、分数和科学计数法。
- 将 `分组合计` 换成 `分组平均`，可按相同的列组合求每组的平均值。例如组内两个值为 `1/2` 和 `2/3` 时，得到 `7/12`。
- 同样可用 `分组最小` 或 `分组最大` 求每组的极值。支持列名和列号，按精确数值比较，结果沿用分组首次出现的顺序。
- 用 `CSV: 分组极差 ["状态"] "金额"` 可求每组最大值与最小值的精确差。只有一个值的组输出 0。
- 用 `CSV: 分组中位数 ["状态"] "金额"` 可按组计算所选数值列的中位数。组顺序取首次出现的位置，每组最多 128 个有效数值。组内为偶数项时，取中间两项的精确平均。
- 用 `CSV: 组内最高 [["地区"],"金额",2]` 加上含表头的表格，可保留每个地区金额最高的两条完整记录。用 `组内最低` 可取最小值。每组按所选数值列排序，同值保留原次序，各组按首次出现的位置输出。列名和列号可以混用。
- 分组计数、合计和平均也支持按表头名称选列，例如 `CSV: 分组平均 ["地区","状态"] "金额"`。分组列用 JSON 数组填写，数组内可以混用列名和列号，每列只能选一次。
- 用 `CSV: 透视合计 ["地区","状态","金额"]` 加上含表头的表格，可按地区生成行、按状态生成列，并在各交叉格显示金额的精确合计。行和列按首次出现的顺序排列，未出现的组合留空。三列可以混用列名和列号。
- 用 `CSV: 透视计数 ["地区","状态"]` 可把每个地区与状态组合的记录数放入交叉表。行和列按首次出现的顺序排列，未出现的组合显示 `0`，可混用列名和列号。
- 用 `CSV: 逆透视 [["地区"],"月份","金额"]` 加上含表头的表格，可保留“地区”，把其余列逐一展开为“月份”和“金额”两列。保留列可混用列名和列号，各行按原列序展开，空单元格照常输出。 [列转行原理](https://learn.microsoft.com/en-us/power-query/unpivot-column)
- 用 `CSV: 左连接 ["编号","键"] ["编号,商品\n001,茶\n002,米","键,金额\n001,1.50"]` 可按两个表头列合并表格。同一个键有多行时逐一匹配，无匹配的左表行保留，右表字段留空。用 `内连接` 可只保留匹配行。连接列也可用从 1 开始的列号，键按原有文本比较。 [连接规则](https://www.postgresql.org/docs/current/queries-table-expressions.html#QUERIES-JOIN)
- 用 `CSV: 全连接` 按相同格式输入两张表，可同时保留双方未匹配的行。只在右表中出现的行按右表顺序附在末尾，右表的键填入输出的连接列，其余左表字段留空。
- 三种 CSV 连接都接受多列键，例如 `CSV: 全连接 [["区","月"],["区域","月份"]]`。两侧按数组顺序配对，只有各列都匹配才连接。列名和列号可混用，只在右表出现的键会填入对应的左表列。
- 用 `CSV: 左表独有 ["编号","键"]` 加上同样格式的两张表，可找出右表没有的编号。用 `左表匹配` 可保留右表有对应键的左表记录。两者都支持多列键，保留左表原有列和行顺序。即使右表的键重复，每条左表记录也只输出一次。
- 用 `CSV: 对比列 [["编号"],"金额"]` 加上同样格式的原表和新表，可按编号查看修改、删除和新增的金额。键可由多列组成，在每张表内须唯一。金额按单元格原文比较，`1.50` 与 `1.5` 会列为一次修改。修改和删除按原表顺序输出，新增按新表顺序附在末尾。
- 换成 `CSV: 数值对比列` 可按精确数值比较，例如 `1.50` 和 `3/2` 视为相等。所选列可以填数字、分数或留空，空白字段视为缺值，改动仍按原来的写法输出。
- 用 `CSV: 纵向合并 ["编号,金额\n001,1.50","金额,编号,备注\n2e0,002,茶"]` 可按表头名称对齐列后追加行。列按名称首次出现的位置排列，各表原有行序保留，缺列留空。每张表的列名须非空且唯一，支持一次输入 2 至 16 张表。
- 输入 `CSV: 排序 2,1` 后粘贴含表头的表格，会先按第二列、再按第一列自然排序，例如“文件2”排在“文件10”之前。用 `降序` 可反向排列，同值行保留原有顺序。
- `CSV: 数值排序 2,1` 按数值比较所选列中的整数、有限小数、分数和科学计数法，例如 `-2.75`、`3/2`、`1.25e1`。用 `数值降序` 可反向排列，同值行保留原有顺序和单元格写法。所选列里的空值或无效数字会提示错误。
- CSV 的排序和按列去重也可用表头名称，例如 `CSV: 数值降序 ["金额"]` 或 `CSV: 按列去重 ["地区","状态"]`。数组内可混用列名和列号。
- 用 `CSV: 多列排序 [["地区","文本升序"],["金额","数值降序"]]` 加上表格，可为每列分别指定排序方式。支持 1 至 8 个不同列，文本按自然顺序比较，数字按精确数值比较。排序值全相等时沿用原行序，单元格内容原样保留。
- 用 `CSV: 列统计 2` 加上含表头的表格，可直接查看第二列的数量、合计、均值、中位数、最值和样本方差。用 `列总体` 可改算总体方差。所选列须有 1 至 128 个有效数值。
- 列统计也可按表头名称选列，例如 `CSV: 列统计 "数值"`。`列总体` 同样支持列名，名称须精确匹配且唯一。
- 用 `CSV: 列分箱 ["金额","0,1/2,2"]` 可直接统计表格中选定列在各区间的次数和精确频率。第一项可填列名或列号，第二项是用逗号隔开的升序边界。区间计入下界，所选列须有 1 至 128 个有效数值。
- 输入 `文本: Base64编码 北京` 得到 `5YyX5Lqs`，输入 `文本: Base64解码 5YyX5Lqs` 可还原文字。`Base64URL编码` 使用网址安全字母表并省略末尾的 `=`。两种解码均接受带或不带 `=` 的对应编码，可粘贴换行分隔的 UTF-8 文本编码。[RFC 4648](https://www.rfc-editor.org/rfc/rfc4648.html#section-4)
- 搜索结果默认预览最多六行。按 `F2` 展开后，每页最多十二行，可用 `PageUp`、`PageDown` 或底部按钮翻页。再按 `F2` 收起，回车复制完整内容。

## 下载 Windows 预览版

运行 `OmniTrigger-<版本>-windows-x86_64-setup.exe` 安装到当前 Windows 用户。开始菜单的 **OmniTrigger** 沿用日常配置，卸载和重装后仍保留。**OmniTrigger 测试** 使用独立的持久配置，默认关闭全局监听。需要便携版时下载 ZIP，完整解压后运行 `omnitrigger.exe`。两个包的摘要见 `SHA256SUMS.txt`。建议使用 Windows 11 x64。[前往下载](https://github.com/ceastld/omnitrigger/releases)

在当前源码构建的安装包中，勾选“登录 Windows 时在托盘启动 OmniTrigger”，下次登录即可使用日常热键。这项设置默认关闭，覆盖安装会记住上次的选择。要关闭它，重新运行安装器并取消勾选即可。

程序未经代码签名。运行需要 [Microsoft Visual C++ v14 Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)；如提示缺少 `VCRUNTIME140.dll`，请安装微软官方运行库。无需安装 Rust 或开发工具。预览版仍有下文说明的输入、焦点与权限限制。

首次启动加载示例绑定：先按住 `CapsLock` 再按 `W`，松开后确认提示浮层和列表中的命中次数；然后测试侧键加滚轮，最后录制一个自定义组合。单独按下并松开未被组合使用的前缀时，会回放原输入。试用步骤、截图插件安装与命令行参数见[快速开始](docs/GETTING_STARTED.md)。

## 输入、权限与隐私

- **前缀与补发**：已注册的前缀按下时暂存输入，组合命中后消费整次按压；遇到不匹配输入或单独松开时回放。鼠标键前缀在指针移出按下点 8 像素后立即交还，拖动不受影响；左键作为前缀时不暂存，按下与释放照常交给应用，只消费完成组合的那次输入（例如“左键 + 右键”中的右键）。延迟与补发会改变时序，不能承诺完全无损。
- **系统限制**：普通权限运行，无需安装驱动；向权限更高的应用补发输入可能失败，此时暂停监听并显示错误。Windows 安全桌面和系统保留组合仍受系统限制；其他软件在上游拦截输入时，OmniTrigger 可能收不到。
- **隐私**：当前应用不提供遥测、云同步或输入上传。配置保存在 `%LOCALAPPDATA%\OmniTrigger\bindings.json`，触发记录和输入诊断仅保留在进程内；版本检查访问 `update.alinko.cc`，失败时回退 GitHub。更新包与插件按用户操作下载，不上传配置或输入记录。

完整说明见[输入语义与边界](docs/INPUT_SEMANTICS.md)、[配置文件与隐私](docs/CONFIGURATION.md)和[并用其他工具与诊断](docs/TROUBLESHOOTING.md)。

## 从源码构建

需要 Windows、Rust（MSVC 工具链）及 Visual Studio C++ Build Tools（含“使用 C++ 的桌面开发”和 Windows SDK）。仓库通过 `rust-toolchain.toml` 固定 Rust 1.90.0、rustfmt 与 Clippy；脚本需要 PowerShell 7。

```powershell
git clone https://github.com/ceastld/omnitrigger.git
cd omnitrigger
.\start.ps1                                      # 构建并打开本机测试配置档
cargo run -p omnitrigger-app --locked -- --test-workspace
.\scripts\check.ps1                               # 与 Windows CI 共用的检查
```

直接启动产物：`target\debug\omnitrigger.exe`。真实 Hook 检查、隔离配置、轮盘入口及主页与文档站的构建方式见[从源码构建](docs/BUILDING.md)。非 Windows 环境可运行 `cargo test -p omnitrigger-core --locked` 验证核心；桌面程序仍仅面向 Windows。

## 核心设计

- **统一描述**：录制器生成 `TriggerSpec`，注册、冲突检查与运行时匹配共享这一份语义。
- **确定性状态机**：核心按 `InputEvent + 显式时间与上下文 → Engine::process_at / advance_time → Decision` 工作，鼠标位置和屏幕矩形由平台显式提供，输出透传、消费、触发通知及必要的补发计划。核心不读取系统时钟，不依赖 UI 或 Windows API；原 `process` 接口沿用最近显式时间。
- **平台适配**：Windows 适配层负责采集输入、执行消费决策和补发；系统 Hook 的同步路径只做有界匹配，不执行动作、网络请求或 Agent 推理。
- **应用层扩展**：`ActionCall` 保存动作身份和输入，动作目录解析契约，`ActionService` 负责有界执行和回执，运行时适配器执行具体实现。当前提供 JavaScript 入口，新增脚本业务无需更改输入核心；不内置流程图，跨动作调用尚未实现。
- **轻量界面**：GPUI 作为候选界面，负责录制、展示、编辑与必要确认，与核心引擎解耦。

插件采用“插件提供预设动作与默认快捷键，OmniTrigger 管理绑定”的方式。RaiShot 动作库由 manifest 生成，内置截图动作，也支持开发者在配置目录放置 RaiShot 多动作清单。默认组合可自定义、恢复并经过统一冲突检查，执行仍在 Hook 之外。已实现范围、本机发现规则与清单格式见[插件动作与快速绑定设计](docs/PLUGIN_SYSTEM.md)；执行路径与扩展边界见[动作执行架构](docs/EXECUTION_ARCHITECTURE.md)。现有 Node 调用示例见[截图脚本](examples/raishot-capture.mjs)。

自定义复杂动作可使用[动作包](docs/ACTION_PACKAGES.md)：在配置同级的 `actions/<包目录>` 放入 `action.json` 和 JS 入口，在动作库选择动作并填写 JSON 参数。Node 入口使用 `export default async function(ctx)`；`await ctx.process.run(...)` 等待程序退出并取得输出，`await ctx.process.start(...)` 独立启动桌面程序后继续后续步骤。`--check-action <call.json>` 只读检查调用，`--run-action <call.json>` 真实执行，`--list-package-actions` 只读列出动作包目录；均可结合 `--config` 指定目录。外部宿主可为运行命令增加 `--stream-action-events`，分别取得开始事件与终态结果。

轻量脚本可选择 `script` 运行时：独立 Rust JS 宿主提供文件、进程、剪贴板、打开目标，以及原目标查询、快捷键、连续按键、文本、选区、窗口操作和浏览器 API，不要求 Node。动作库支持新建脚本、启动本地编辑器和重新加载目录；工程附带 SDK 与编辑器配置，使用标准 `function main(ctx)` 入口。开发命令仍提供 `--create-script-action`；安装与现有能力见[轻量脚本宿主](docs/ACTION_PACKAGES.md#轻量脚本宿主)。

## 工程结构

| 目录 | 职责 |
| --- | --- |
| `crates/omnitrigger-core` | 无外部依赖的模型、注册验证、状态机、录制器与区域计算；按职责分模块并保留统一公共 API。 |
| `crates/omnitrigger-windows` | Windows 输入采集、消费 / 补发、窗口与系统操作；隔离原生 API。 |
| `crates/omnitrigger-actions` | 通用动作契约、包目录、运行时注册、有界执行与 Node.js 宿主。 |
| `crates/omnitrigger-app` | GPUI 界面、持久化、动作分派、后台执行器与插件安装。 |
| `docs` / `examples` | 使用与架构文档、可通过 `--check-config` 验证的配置示例。 |
| `site` | 主页与文档站，从 `docs` 等仓库文档同步生成。 |
| `scripts` / `.github` | 本地检查入口、CI、站点发布和协作模板。 |

模块定位、事件流和后续拆分边界见[项目架构](docs/ARCHITECTURE.md)。
